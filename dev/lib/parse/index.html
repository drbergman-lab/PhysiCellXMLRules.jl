Parse

Parse an XML rules file into a typed Vector{BehaviorRuleset} hierarchy. The parser is strict (the first malformed behavior raises an ArgumentError); see Validate for a collect-errors variant.

PhysiCellXMLRules.BehaviorRuleset — Type
BehaviorRuleset(cell_type::String, behaviors::Vector{Behavior})

The parsed representation of a single <behavior_ruleset> element from a rules XML file. Returned (in a vector) by parseRulesXML.

source
PhysiCellXMLRules.parseRulesXML — Method
parseRulesXML(path_to_xml::AbstractString) -> Vector{BehaviorRuleset}

Parse a PhysiCell rules XML file into the BehaviorRuleset / Behavior / MediatorSignal / AggregatorSignal / elementary-signal hierarchy.

The parser is strict: any non-conforming element raises an error. To collect errors into a report instead, use validateRulesXML.

Signal type names, mediator names, and aggregator names are matched case-insensitively and treat space/underscore/hyphen as equivalent, so "PartialHill", "partial_hill", and "partial hill" all parse identically.

source
PhysiCellXMLRules.writeXMLRules — Method
writeXMLRules(path_to_xml::AbstractString, rulesets::AbstractVector{BehaviorRuleset}; force::Bool=false)

Serialise an already-parsed BehaviorRuleset tree back to a rules XML file at path_to_xml. Pair with parseRulesXML to round-trip a rules file, or use it to save modifications you've made to the typed tree in memory.

Hierarchical sub-signals are still v2; for now this overload supports the elementary-signal shape that the parser and explorer both produce.
