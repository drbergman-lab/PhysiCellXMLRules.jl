PhysiCellXMLRules

Documentation for PhysiCellXMLRules.

PhysiCellXMLRules defines, parses, validates, and converts the XML rules format consumed by the extended PhysiCell rules grammar. The package lets you:

  • writeXMLRules — convert a CSV rules file to the XML format, or serialise a (modified) BehaviorRuleset tree back to XML
  • exportCSVRules — export an XML rules file back to a (possibly lossy) CSV approximation
  • parseRulesXML — parse an XML rules file into a typed Julia hierarchy (BehaviorRuleset → Behavior → MediatorSignal → AggregatorSignal → elementary signals)
  • validateRulesXML — check that a rules XML file conforms to the standard and surface common modelling pitfalls
  • summarizeRulesXML — print a human-readable tree view of every behavior in a rules XML file
  • evaluateBehavior — compute the rule's output (behavior value for setters, rate of change for accumulator/attenuator) at a given set of raw signal values
  • exportInteractiveHTML — write a single self-contained HTML file for exploring the rules in the browser (1D dose-response and 2D heatmaps, live parameter editing, save back to XML)
  • A Plots.jl recipe (loaded automatically when RecipesBase / Plots is present): plot(behavior; vary="oxygen") for 1D dose-response or plot(behavior; vary=("oxygen","pressure")) for 2D

See the Guide for installation and a quick tour, the Features page for the full list of supported transformers / aggregators / mediators / behavior types / id attribute semantics, and the Examples page for worked rulesets including the interactive explorer.
